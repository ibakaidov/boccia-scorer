# Тестовая стратегия

Тесты обязательны, потому что старый счетчик не имел автоматической защиты от регрессий.

## Инструменты

| Уровень | Инструмент |
|---|---|
| Unit | Vitest |
| Component | Vue Testing Library |
| E2E | Playwright |
| Mock API | MSW или тестовый сервер |
| Timer tests | Fake timers Vitest |

## Unit-тесты

| Модуль | Кейсы |
|---|---|
| Классы | Количество эндов, время, активность, сортировка |
| Счет | Сумма по эндам, победитель, равенство |
| Тай-брейк | Создание, повторный тай-брейк, победитель |
| Таймеры | Старт, пауза, тик, ручная коррекция, достижение нуля |
| Offline queue | Добавление, retry, failed, synced |
| Action log | Запись действий, порядок, payload |

## Component-тесты

| Компонент | Кейсы |
|---|---|
| Timer | Показывает время, стартует, останавливается, блокирует отрицательное время |
| ScoreControls | Меняет счет без подтверждения, пишет action log |
| MatchSetup | Позволяет начать автономный матч по классу без игроков и сервера |
| Scoreboard | Отображает режимы warmup/end/tieBreak/protocol |
| Settings | Валидирует времена и классы |

## Integration-тесты

| Интеграция | Кейсы |
|---|---|
| Pinia + storage | Снимок матча сохраняется после действия |
| Operator + scoreboard | Изменение счета обновляет табло |
| API client + queue | Ошибка сети переводит задачу в pending |
| Settings + game classes | Изменение времени класса влияет на новый матч |

## E2E-тесты

| Сценарий | Описание |
|---|---|
| Индивидуальный матч 4 энда | Полный матч без тай-брейка |
| Командный матч 6 эндов | Проверить `ТВС1/ВС2` |
| Пары BC3 | Проверить 7 минут на энд |
| Тай-брейк | Равный счет после основных эндов, затем победитель |
| Offline start | Сервер недоступен, матч ведется из кэша |
| Offline sync | Если сервер настроен позже, задачи отправляются |
| Автономное завершение | Матч завершается без кода/пароля |
| Server-mode завершение | Код проверяется только если требует сервер |

## Регрессионные тесты по старому проекту

| Баг старого проекта | Тест v2 |
|---|---|
| Hardcoded IP | Сервер задается настройкой |
| Offline-mode ломает игроков | Offline больше не зависит от выбора игроков |
| `ТВС1/ВС2` сравнивался с опечаткой | Количество эндов берется из справочника |
| Массивы не сокращались после смены класса | Новый матч строится из параметров класса |
| `name/fullName` конфликт | Участники являются опциональными метаданными, автономный матч от них не зависит |
| Нет сохранения завершенных матчей | Завершенный автономный матч сохраняется в SQLite |

## CI

Минимальный pipeline:

1. Установка зависимостей.
2. Typecheck.
3. Lint.
4. Unit-тесты.
5. Component-тесты.
6. E2E smoke.
7. Сборка Electron.
