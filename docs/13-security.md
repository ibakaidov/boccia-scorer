# Безопасность

Старый проект использовал небезопасный Electron-паттерн: `nodeIntegration: true` и прямой доступ renderer к `ipcRenderer`.

В v2 это запрещено.

## Electron

| Настройка | Требование |
|---|---|
| `nodeIntegration` | `false` |
| `contextIsolation` | `true` |
| `sandbox` | включить, если совместимо |
| `preload` | единственный способ открыть API renderer |
| `webSecurity` | не отключать |
| CSP | задать строгую политику |

## Preload API

Renderer не должен получать сырой `ipcRenderer`.

Разрешен только ограниченный API:

```ts
window.bocciaApi = {
  settings: {
    load: () => Promise<Settings>,
    save: (settings: Settings) => Promise<void>
  },
  match: {
    saveSnapshot: (snapshot: MatchSnapshot) => Promise<void>
  },
  scoreboard: {
    onUpdate: (handler: (state: ScoreboardState) => void) => Unsubscribe
  }
}
```

## IPC

Все IPC handlers должны валидировать:

| Проверка | Назначение |
|---|---|
| Канал | Только allowlist каналов |
| Payload | Runtime validation |
| Sender | Только ожидаемые окна |
| Путь файла | Renderer не передает произвольные пути |

## Локальные файлы

Renderer не должен выбирать путь для чтения или записи.

Main process сам определяет директорию данных приложения.

Запрещено делать IPC вида `readFile(path)` или `writeFile(path, data)` для произвольного `path` из renderer.

## Код завершения матча

В автономном режиме код/пароль завершения не нужен.

В серверном режиме сервер может требовать код/пароль для финальной отправки. Если код используется, он не должен быть hardcoded в UI.

Варианты:

| Вариант | Комментарий |
|---|---|
| Серверная проверка | Предпочтительно при online/server-mode |
| Локальный hash в настройках | Не нужен для автономного режима |
| Hardcoded `2007` | Запрещено |

## Данные

| Данные | Требование |
|---|---|
| Игроки | Хранить только в server-mode, если сервер передает участников |
| Журнал действий | Не хранить лишние персональные данные |
| Настройки | Не хранить секреты в plain text, если возможно |
| Sync queue | Идемпотентные идентификаторы вместо дублей |

## Сеть

Сканирование всей локальной сети, как в старом проекте, не должно быть поведением по умолчанию.

Сервер задается настройкой или discovery-механизмом, который явно разрешен организатором.
