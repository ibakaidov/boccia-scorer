# Доступность

Приложение используется в спортивной среде, где важны читаемость, скорость и низкая вероятность ошибки.

## Основные требования

| Требование | Описание |
|---|---|
| Крупный текст | Табло и таймеры должны быть видны с расстояния |
| Контраст | Красная/синяя стороны и текст должны читаться при ярком свете |
| Клавиатура | Основные действия доступны без мыши |
| Не только цвет | Стороны подписываются текстом |
| Ясный фокус | Видно, какой элемент активен при управлении клавиатурой |
| Стабильная верстка | Кнопки не прыгают при изменении времени или счета |

## Окно оператора

Минимальный размер интерактивных элементов: не меньше 44x44 px.

Кнопки `Старт`, `Пауза`, `Отправить энд`, `Завершить матч` должны иметь разные цвета и текстовые подписи.

Ошибки должны выводиться рядом с проблемным действием и в общем уведомлении.

## Табло

Табло должно быть оптимизировано для второго монитора.

Требования:

| Элемент | Требование |
|---|---|
| Таймер | Самый крупный элемент в зоне стороны |
| Счет | Крупный и контрастный |
| Имена | Сокращение должно быть предсказуемым |
| Энд | Видимый индикатор текущего энда |
| Статус тай-брейка | Отдельная крупная метка |

## Горячие клавиши

Подсказка по горячим клавишам должна быть видна на экране энда.

Если фокус находится в текстовом поле или select, горячие клавиши управления матчем не должны срабатывать.

## Язык

Интерфейс только русский.

Архитектура не обязана поддерживать мультиязычность в v2.
