# Документация Boccia Scorer v2

Папка `docs` описывает новый счетчик для игры бочча: продуктовые требования, правила, архитектуру, данные, API, UX, тесты, безопасность, эксплуатацию и миграцию со старого счетчика.

Проект пишется заново на `Vue 3 + Vite + Electron + TypeScript`. Старый проект находится рядом: `../boccia-scorer`.

## Ключевые решения

| Тема | Решение |
|---|---|
| Язык интерфейса | Только русский |
| Клиент | Vue 3, Vite, TypeScript |
| Десктоп | Electron |
| Состояние | Pinia |
| Табло | Второе окно Electron |
| Сервер | Опционален; для больших соревнований будет переработанный сервер, для малых соревнований приложение работает автономно |
| Offline-mode | Обязателен; малые соревнования можно провести вообще без сервера |
| Игроки offline | Не требуются; автономный матч можно вести только по классу и цветам сторон |
| Регион/команда/страна | Не требуются для автономного матча; возможны только как расширенные серверные метаданные |
| Завершение матча | В автономном режиме без кода; в серверном режиме код может требоваться сервером |
| Лог действий | Нужен |
| Подтверждение каждого изменения счета | Не нужно |
| Незавершенный автономный матч | Не требуется автосохранение и восстановление после перезапуска |
| Хранение завершенных матчей | SQLite |
| Экспорт протокола | Только отправка на сервер |
| Экспорт для малых соревнований | Не нужен |
| Автономный турнир | Не нужен; один матч за раз |
| Платформы | Windows, Linux, macOS |

## Автономный режим

Приложение должно уметь полностью работать без сервера для малых соревнований.

В автономном режиме не нужна база игроков. Минимальная настройка матча: выбрать класс и вести красную/синюю сторону. Корт, судьи, этап, игроки, команды и регионы не обязательны. Этого достаточно для малых соревнований, где важны счет, время и протокол по цветам.

Если сервер появится позже, локальные матчи могут быть синхронизированы через очередь. Если сервер не используется вообще, соревнование все равно можно провести, завершить и сохранить локально.

Выбор игроков, регионов, команд и стран является опциональным расширением для больших соревнований и серверной интеграции, а не обязательным условием работы счетчика.

## Правила

Официальный источник правил: <https://www.worldboccia.com/about-boccia/rules/>

Локальная копия PDF скачана в проект: `docs/world-boccia-rules-2025-2028-v1.2.1.pdf`.

Используемая редакция: `World Boccia International Sport Rules 2025-2028 v.1.2.1`, апрель 2026. Английская версия является официальной для разрешения споров.

Текст правил был извлечен локально через `pdftotext` из пакета `poppler-utils`. Пользователь разрешил устанавливать инструменты для парсинга правил.
