# Современный стек

## Выбранный стек

| Область | Технология |
|---|---|
| UI | Vue 3 |
| Сборка renderer | Vite |
| Десктоп | Electron |
| Связка Electron/Vite | electron-vite или эквивалентная Vite-сборка |
| Язык | TypeScript |
| Состояние | Pinia |
| Роутинг | Vue Router 4 |
| Unit-тесты | Vitest |
| Component-тесты | Vue Testing Library |
| E2E | Playwright |
| Линтинг | ESLint |
| Форматирование | Prettier |

## Почему Vue 3

Старый проект уже написан на Vue, поэтому Vue 3 снижает стоимость переноса концепций и UI-паттернов.

Vue 3 поддерживается актуальной экосистемой, лучше типизируется и хорошо работает с Vite.

## Почему Vite

Vue CLI находится в режиме поддержки. Новый проект должен использовать Vite из-за скорости разработки, современной сборки и лучшей интеграции с Vitest.

## Почему Pinia

Pinia является актуальным state manager для Vue. Для счетчика важны явные store-модули: матч, таймеры, настройки, синхронизация, справочники.

## Почему Electron остается

Требуется второе окно табло на втором мониторе. Electron дает контролируемый десктопный сценарий, доступ к окнам, локальному хранению и упаковке под Windows/Linux/macOS.

## Минимальные версии

Точные версии фиксируются при создании проекта, но требования такие:

| Компонент | Требование |
|---|---|
| Node.js | LTS или актуальная версия, совместимая с выбранным Electron/Vite |
| Electron | Актуальная поддерживаемая версия |
| Vue | Vue 3 |
| TypeScript | Strict mode |

## Структура будущего проекта

```text
src/
  main/          # Electron main process
  preload/       # безопасный bridge для IPC
  renderer/      # Vue 3 приложение оператора и табло
  shared/        # общие типы, схемы, утилиты
```

## Принципы разработки

| Принцип | Требование |
|---|---|
| Типы сначала | Все payload, IPC и API описываются TypeScript-типами |
| Справочники как данные | Классы и времена не хардкодятся в бизнес-логике |
| Тестируемая логика | Расчет счета и таймеры выносятся из компонентов |
| Безопасный Electron | Renderer не получает прямой доступ к Node.js |
| Offline-first для матча | Матч пишется локально, серверная отправка идет отдельно |
