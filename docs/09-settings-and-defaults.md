# Настройки и дефолты

Настройки должны редактироваться на месте соревнования. Классы и времена являются данными, а не хардкодом.

## Источник дефолтов

Основной источник дефолтов: `World Boccia International Sport Rules 2025-2028 v.1.2.1`.

Локальный PDF: `docs/world-boccia-rules-2025-2028-v1.2.1.pdf`.

Если технический делегат или локальный регламент соревнования уточняет настройки, любой оператор может изменить их в приложении. Отдельный пароль администратора для настроек не требуется.

## Общие дефолты

| Настройка | Значение |
|---|---:|
| Разминка | 120 сек |
| Сбор мячей | 60 сек |
| Штрафной мяч | 60 сек |
| Технический тайм-аут | 600 сек |
| Автосохранение незавершенного автономного матча | выключено |
| Хранение завершенных матчей | SQLite |
| Очередь offline sync | включена |
| Язык интерфейса | русский |
| Подтверждение каждого изменения счета | выключено |
| Подтверждение отправки энда | включено |
| Код/пароль завершения матча | выключен в автономном режиме; может быть включен сервером |
| Журнал действий | включен |

## Разделы настроек

| Раздел | Поля |
|---|---|
| Сервер | URL, порт, статус подключения, ручная проверка |
| Справочники | Классы, времена, корты, импорт расширенных серверных данных при необходимости |
| Классы | Активность, название, тип, количество эндов, время, порядок |
| Таймеры | Разминка, сбор мячей, штрафной мяч, технический тайм-аут |
| Горячие клавиши | Назначение клавиш и сброс к дефолтам |
| Безопасность | Политика серверного кода завершения, если сервер его требует |
| Storage | SQLite для истории завершенных матчей, размер очереди, очистка старых логов |

## Автономный режим без базы игроков

Для малых соревнований приложение должно работать без сервера.

В настройках нужен раздел автономного режима:

| Возможность | Назначение |
|---|---|
| Настроить классы | Подготовить времена и количество эндов |
| Настроить корты | Опционально задать номера/названия кортов |
| Импортировать расширенные данные | Опционально загрузить участников для большого соревнования |
| Проверить готовность | Убедиться, что можно начать матч по классу без сервера |
| История матчей | Хранить завершенные матчи в SQLite |

В автономном матче игроки не выбираются. Минимальная настройка матча: класс и стороны `Красные`/`Синие`.

## Хранение настроек

Настройки должны храниться локально в пользовательской директории приложения, а не в произвольном пути из renderer.

Варианты:

| Вариант | Комментарий |
|---|---|
| JSON | Достаточно только для простых настроек |
| SQLite | Обязательный выбор для завершенных матчей, очереди sync и журнала |

Если используется JSON для настроек, файл должен иметь версию схемы.

```json
{
  "schemaVersion": 1,
  "language": "ru",
  "server": {
    "baseUrl": "http://localhost:2007/api/v2"
  },
  "timers": {
    "warmupSec": 120,
    "collectBallsSec": 60,
    "penaltyBallSec": 60,
    "technicalTimeoutSec": 600
  },
  "gameClasses": []
}
```

## Сброс к дефолтам

Сброс к дефолтам должен требовать подтверждения.

Сброс не должен удалять текущий матч, очередь синхронизации и журнал действий.

## Валидация настроек

| Поле | Правило |
|---|---|
| Количество эндов | Целое число больше 0 |
| Время | Целое число больше 0 |
| Код класса | Уникальный непустой код |
| Активность класса | Не удалять использованные классы, только деактивировать |
| URL сервера | Валидный URL |
