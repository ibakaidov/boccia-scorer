# UX/UI

Интерфейс должен быть быстрым, контрастным и устойчивым к ошибкам оператора.

## Принципы

| Принцип | Требование |
|---|---|
| Минимум действий | Частые операции выполняются в один клик или клавишу |
| Крупные элементы | Таймеры, счет и основные кнопки видны сразу |
| Ясные состояния | Оператор видит фазу матча, активный таймер и статус sync |
| Безопасные подтверждения | Подтверждать только опасные действия, не каждое изменение счета |
| Простота автономного режима | Для малого соревнования нужен только выбор класса |

## Экран запуска

Показывает:

| Элемент | Назначение |
|---|---|
| Статус сервера | Online/offline |
| Статус справочников | Когда обновлялись |
| Незавершенный матч | Восстановление не обязательно для автономного режима |
| Очередь синхронизации | Количество pending/failed задач |

## Настройка матча

В автономном режиме оператор не выбирает игроков. Он выбирает класс, после чего приложение создает красную и синюю сторону.

В серверном режиме может быть доступен выбор матча из расписания или участников, но это расширение, а не обязательная часть счетчика.

Поля:

| Поле | Тип |
|---|---|
| Корт | Не обязателен в автономном режиме |
| Класс | Select из активных классов |
| Красная сторона | Автоматически `Красные`; опционально участники из сервера |
| Синяя сторона | Автоматически `Синие`; опционально участники из сервера |
| Судья на корте | Не нужен в автономном режиме; опционален в server-mode |
| Судья на счетчике | Не нужен в автономном режиме; опционален в server-mode |

Если приложение offline, матч можно начать без игроков.

Если классы не настроены, создание матча блокируется с понятным сообщением.

## Экран разминки

Показывает крупный таймер `02:00`, кнопки старт/пауза/сброс и переход к эндам.

Для индивидуальных матчей разминка может отображаться как общий таймер.

Для пар и команд можно показывать сторону, которая разминается.

## Экран энда

Основной экран оператора.

Обязательные зоны:

| Зона | Содержание |
|---|---|
| Верхняя панель | Класс, энд, online/offline/sync; корт только если указан |
| Красная сторона | Имя/состав, таймер, счет энда, общий счет |
| Синяя сторона | Имя/состав, таймер, счет энда, общий счет |
| Центральная зона | Активное действие, отправка энда, сбор мячей |
| Нижняя подсказка | Горячие клавиши |

## Табло

Табло работает во втором окне и не содержит элементов управления.

Режимы табло:

| Режим | Отображение |
|---|---|
| Ожидание | Статус ожидания; корт только если указан |
| Разминка | Один крупный таймер |
| Сбор мячей | Один крупный таймер и подпись |
| Энд | Красная и синяя стороны, счет, время, текущий энд |
| Тай-брейк | Явная метка `Тай-брейк` |
| Протокол | Итоговый счет и таблица эндов |

## Цвета

Красная сторона должна быть визуально красной, синяя - синей.

Нельзя полагаться только на цвет. Нужно дублировать текстом: `Красные`, `Синие`.

## Подтверждения

Подтверждать нужно:

| Действие | Подтверждение |
|---|---|
| Отправить энд | Да |
| Завершить автономный матч | Да, без кода/пароля |
| Завершить server-mode матч | Да, код/пароль только если требует сервер |
| Сбросить матч | Да |
| Сбросить настройки | Да |
| Удалить локальный кэш | Да |

Не нужно подтверждать:

| Действие | Причина |
|---|---|
| Плюс/минус счет | Слишком частое действие |
| Старт/пауза таймера | Слишком частое действие |
| Ручная коррекция времени | Логируется и видна оператору |
