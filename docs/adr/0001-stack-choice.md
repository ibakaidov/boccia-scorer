# ADR 0001: выбор стека

## Статус

Принято.

## Контекст

Старый счетчик написан на Vue 2, Vuex, Vuetify 2, Vue CLI и Electron 11.

Новый проект должен быть современным, поддерживаемым, тестируемым и пригодным для десктопной сборки под Windows, Linux и macOS.

Пользователь выбрал Vue 3.

## Решение

Использовать стек:

| Область | Выбор |
|---|---|
| UI | Vue 3 |
| Сборка | Vite |
| Desktop | Electron |
| State | Pinia |
| Router | Vue Router 4 |
| Language | TypeScript strict |
| Unit tests | Vitest |
| E2E | Playwright |

## Последствия

Плюсы:

| Плюс | Объяснение |
|---|---|
| Меньше стоимость миграции | Старый проект уже на Vue |
| Современная сборка | Vite быстрее и актуальнее Vue CLI |
| Хорошая тестируемость | Vitest естественно работает с Vite |
| Поддерживаемость | Vue 3 и Pinia являются актуальным стеком |

Минусы:

| Минус | Митигировать |
|---|---|
| Нужно переписать Vue 2 class components | Не переносить напрямую, писать Composition API/standard Vue 3 |
| Нужно заново настроить Electron security | Делать preload и typed IPC с первого дня |
