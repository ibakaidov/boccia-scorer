# Открытые вопросы

Большая часть ключевых решений уже зафиксирована. Этот файл хранит вопросы, которые нужно закрывать по мере реализации.

## Закрытые решения

| Вопрос | Решение |
|---|---|
| Нужна ли мультиязычность? | Нет, только русский |
| Нужен ли выбор игроков в автономном матче? | Нет, только класс и стороны `Красные`/`Синие` |
| Должна ли программа работать вообще без сервера? | Да, для малых соревнований без базы игроков |
| Нужен ли ввод региона/команды/страны в автономном матче? | Нет |
| Можно ли менять сервер? | Да, сервер тоже будет переработан |
| Нужен ли код/пароль завершения в автономном режиме? | Нет |
| Нужен ли код/пароль завершения в server-mode? | Только если требует сервер |
| Нужен ли лог действий? | Да |
| Нужно ли подтверждать каждое изменение счета? | Нет |
| Кто может менять настройки классов и времени? | Любой оператор, без пароля администратора |
| Нужен ли экспорт для малых соревнований? | Нет |
| Нужен ли автономный турнир? | Нет, один матч за раз |
| Нужен ли этап в автономном режиме? | Нет |
| Где хранить завершенные автономные матчи? | SQLite |
| Нужны ли судьи в автономном режиме? | Нет |
| Нужен ли корт для старта автономного матча? | Нет, обязателен только класс |

## Еще нужно уточнить

| Вопрос | Почему важно |
|---|---|
| Где хранить локальные данные? | SQLite для завершенных матчей; JSON допустим для простых настроек |
| Как сервер будет моделировать пары и команды? | Влияет на выбор сторон из базы |
| Нужен ли отдельный endpoint для расписания матчей? | Влияет на экран выбора матча |
| Какие статусы матча нужны серверу? | Влияет на sync contract |
| Нужно ли хранить старые завершенные матчи локально? | Влияет на размер storage и очистку |
| Нужно ли шифровать локальные данные? | Влияет на security и поддержку |
